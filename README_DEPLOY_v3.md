# DT 통합 배포 v3 · 토큰 링크 + 개인정보 게이트 + 조준모의고사 숙제

작성: 2026-07-06 · 기준: 라이브(pre_token 정합 세트) 위에 1회 배포로 전부 적용

## 0. 이 번들이 합친 것

1. 토큰 리포트 링크 (v2 마지막 레이어): 링크는 `report.html?student=학교-이름-토큰8자`. 토큰 없거나 틀리면 서버가 빈 결과를 반환.
2. 개인정보 게이트: 키 없는 전체 조회 차단, roster/pending/absentees/exclude/명단저장/메일발송은 관리자 코드 필수. index 반 패널은 익명 집계(action=cohortmis)만 사용.
3. 조준모의고사 화학 I 숙제: 1페이지 OMR(별도 PDF, 인쇄용) 제출 -> hw_grader.html 에서 일괄 입력 -> 리포트의 [숙제 제출 · 피드백 보기] 버튼. OX 워밍업은 해설지 자가채점(디지털 미수집).
4. home.html 신규 랜딩(구세대 링크 제거), exam.html 반 명단 드롭다운, report 엔진 학교명 정규화 동기화.
5. pending.html 에 "시험 미응시" 섹션 추가: roster 미응시자(정식 시험 자체를 안 본 학생)를 반별로 보여주고, 온라인 응시 안내 카톡을 학생별(1차/리마인드) + 반 전체 공지로 복사. 링크는 응시 페이지(exam.html?c=&r=).

전제 확인 완료: 시트 결과 탭은 이미 신 컬럼 순서(D=점수)이므로 reorderColumnsToNew 는 실행하지 않습니다.

## 1. 배포 순서 (응시 없는 시간에 1~4를 한 호흡으로)

1) Apps Script: 시트 > 확장 프로그램 > Apps Script > 기존 코드 전체 삭제 후 `apps-script.gs` 붙여넣기 > 저장
2) 좌측 톱니(프로젝트 설정) > 스크립트 속성 2개 추가
   - `ADMIN_TOKEN` : 관리자 코드 (선생님만, 임의의 12자 이상)
   - `STUDENT_CODE` : 반 코드 (학생 공지용 짧은 값, 예: dw2026)
3) 배포 > 배포 관리 > 연필(편집) > 버전: **새 버전** > 배포
   - 절대 "새 배포"를 만들지 않습니다. /exec URL이 바뀌어 전 링크가 깨집니다.
4) 편집기에서 `resyncAllKeysLinks` 1회 실행 -> 시트 B열 링크가 전부 토큰 링크로 갱신됩니다.
5) 저장소 /DT/ 에 웹 파일 업로드(아래 표) 후 push. GitHub Pages 반영(~1분)까지가 유일한 전환 창입니다.
6) 트리거 확인(편집기 좌측 시계 아이콘): `onEditSync`(시트 편집), `weeklyPendingEmail`(수 18시), `weeklyAbsenteeEmail`(월 18시), 선택 `applySheetColors`(매일 6시). 없는 항목은 대응 setup 함수를 1회 실행.
7) 기존에 공유된 무토큰 링크는 3) 순간 전부 무효입니다. 시트 B열 링크 또는 pending.html 의 단계별 카톡 버튼으로 재공유하세요.

## 4. 운영 루틴 (숙제)

1) 인쇄: `wb_submit_1page.pdf` 를 인원수만큼 (모든 회차 공용 · 회차는 학생이 기입)
2) 학생: 워크북 풀이 후 객관식 20답 마킹, OX 워밍업은 해설지로 자가채점 · 수업 시작 시 제출
3) 입력: hw_grader.html 에서 회차 고정 -> 카드 순서대로 학생 클릭 -> 키보드 1~5 로 20답 입력 -> [채점하고 저장] -> 자동으로 다음 학생. 같은 (학생·회차) 재입력은 덮어쓰기라 정정도 다시 입력하면 됩니다.
4) 확인: 학부모/학생은 리포트의 [숙제 제출 · 피드백 보기]. 최근 테스트일 기준 8일 안 제출이면 "이번 주 제출" 배지.

## 4-1. 미응시 관리 (pending.html)

pending.html 은 두 종류를 한 화면에서 관리합니다.
- 시험 미응시(상단): 정식 시험 자체를 아직 안 본 학생. roster 명단과 시트 응시 기록을 대조해 반별로 표시. 학생별 [1차 안내]/[리마인드], 반 단체방용 [반 전체 공지] 복사. 안내 링크는 해당 회차 응시 페이지로 바로 연결됩니다.
- 재시 미응시(하단): 미통과 후 재시를 안 본 학생(기존 3단계 카톡).
- 미응시 명단의 회차는 roster 의 반별 설정(또는 최근 8일 내 채점된 회차)을 따릅니다. 특정 회차로 고정하려면 roster 에서 반의 회차를 지정하세요.

## 5. 코드 2종

- 관리자 코드(ADMIN_TOKEN): 선생님 전용. roster/pending/admin/hw_grader 최초 1회 입력(브라우저 저장).
- 반 코드(STUDENT_CODE): 학생 공지용. exam/hw_grader 의 이름 드롭다운에만 사용, 성적 조회 권한과 무관.
- 변경: 스크립트 속성 수정 -> 새 버전 재배포. 저장된 옛 코드는 자동 무효화되어 다시 묻습니다.
- 속성 미설정 시: 관리자 기능 잠김(fail-closed), 드롭다운 비활성. 학생 응시/저장/토큰 리포트는 정상.

## 6. 이번 병합에서 수정한 잠복 버그 (기록)

1. index 첫 화면의 학생 이력/재시 로딩이 무토큰 조회 -> 새 서버에서 조용히 빈 값이 되는 문제. 토큰을 실어 해결.
2. report 정오표가 회차 번호만으로 행을 모아, 같은 회차 번호의 숙제(jm1) 행이 생기면 오염되는 문제. 과목 필터 추가.
3. report 엔진의 학생키가 학교명 정규화를 안 해 '휘문중학교' 입력 시 키가 어긋나던 문제. normSchool 동기화.
4. hw_grader 저장 성공 메시지가 자동 다음-학생 전환에 지워지던 문제. 메시지 유지.

## 7. hw_jm1.json 메모

- 정답키는 해설지 교차검증 감사본: 전역 48번은 빠른정답 오타로 판정되어 4 확정, 전역 128번(7회 8번)은 해설지 삭제처리 표기이나 워크북 의도정답 1 유지. 전원정답 처리하려면 key 의 7회 8번째 값을 수정.
- 문항 메타(출처/정답률/지문)는 현재 비어 있음(meta:{}). 워크북 PDF를 다시 주면 재파싱해 채울 수 있고, 채우면 리포트 오답 카드에 출처·전국 정답률·지문이 함께 표시됩니다. 비어 있어도 정답/내 답/해설 페이지는 전부 동작.
