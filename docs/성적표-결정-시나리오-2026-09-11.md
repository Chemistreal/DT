## 1. 화학Ⅱ 1·2회 해설지 — 실제로 무엇을 치렀는가 〔급함〕

**지금.** `haeseol_ch2_round01.html` 은 JSON 1회 문항을 18/60 만 담고 2회 문항을 57/60 담는다. 2회 HTML 도
거꾸로다. 즉 **HTML 과 JSON 의 1·2회가 통째로 뒤바뀌어 있다.** 시트에 저장된 학생 답안(answers 열)은
어느 문항 순서로 채점됐는지가 걸려 있다 — JSON 순서라면 성적표의 문항별 정오는 맞고 해설지가 틀린
것이고, HTML(인쇄물) 순서라면 성적표 쪽이 틀린 것이다.

| 고르면 | 무엇이 달라지나 | 코드 |
|---|---|---|
| **A. 인쇄물(HTML)이 실제 시행분** | JSON 1회↔2회를 맞바꾼다. 시트의 1·2회 답안이 바뀐 JSON 으로 다시 채점되므로 그 학생들의 문항별 정오·오개념 목록이 바뀔 수 있다(점수는 시트에 저장된 값이라 안 바뀐다). | JSON 두 파일 맞바꾸기 + `tools/haeseol_sync.py --write` + 성적표 재확인 |
| **B. JSON 이 실제 시행분** | HTML·PDF 1회↔2회를 맞바꾼다. 학생 화면은 그대로이고 해설지만 바뀐다. | HTML 2장·PDF 2장·versions 2개 이름 바꾸기 + `--write` |

**확인하는 법.** 시트의 화학Ⅱ 1회 응시 행 하나를 열어 answers 첫 열 자를 보고, 1번 문항이 JSON 1회의
1번(정답 O/X)과 맞는지 인쇄물 1번과 맞는지 대 본다. 학생 여럿의 정답률로 보면 금방 갈린다.
**권고.** 확인 전에는 아무것도 바꾸지 않았다. `haeseol_sync.py --check` 가 이 둘을 「선생님 확인 대기」로
찍는다.

## 3. 「반복해서 막히는 곳」(고질) 문턱 〔보통〕

**지금.** 어떤 오개념을 **2개 회차 이상** 틀리면 고질. 출제 여부는 안 본다. 오늘부터 화면에 「출제 M회 중
N회 틀림」 분모가 같이 찍힌다(판정 규칙은 그대로). 무작위 오답만으로도 85점 학생은 4회차 뒤 4개, 8회차 뒤
10개, 18회차 뒤 24개가 고질에 오른다.

| 고르면 | 무엇이 달라지나 |
|---|---|
| **A. 「출제 3회 이상 · 절반 이상 틀림」** | 초반(응시 2~3회차)에는 고질이 거의 안 뜨고, 회차가 쌓일수록 정확해진다. 우연 고질이 크게 준다. 「이번 주 확인할 개념」은 고질이 없으면 이번 회차 오답 중 첫 것을 쓴다(지금 논리 그대로). |
| **B. 「틀린 문항 수 ≥ 3 (회차 무관)」** | 한 회차에 같은 개념 3문항을 틀린 강한 증거를 살린다(지금은 저장 단계에서 버려진다 — 성적표가 answers × 회차 파일로 복원할 수 있다). 개념당 문항이 적으면 영영 안 뜬다. |
| **C. A + B 둘 중 하나** | 가장 넓다. 우연 고질도 조금 는다. |
| **D. 지금 그대로(≥2회차)** | 분모만 보이고 규칙은 그대로. 회차가 쌓일수록 목록이 길어진다. |

**권고.** A. 문턱 값(3회·50%)은 정해 주시면 상수 하나다. 화면에는 「출제 M회 중 N회」가 이미 있으니 학부모가
스스로 가늠할 수 있다.

## 10. 첫 화면의 말 — 판정 하나, 독자 하나, 「이번 주」 하나 〔보통〕

**지금.** 첫 화면에 판정 말이 셋(안정/주의/집중 관리 · 처방 코멘트 등급 · 위험 판정)이고, 「이번 주 처방을
우선 진행해 주세요」 가 어느 카드인지 이름이 없고, 문장이 아이와 부모 사이를 오간다. 「이번 주」 목표도
둘이다 — 부모 쪽 카드는 고질 개념, 아이 쪽은 이번 회차 오답.

| 정할 것 | A | B |
|---|---|---|
| **판정** | 셋 중 하나(예: 안정/주의/집중 관리)만 남긴다. | 셋을 두되 이름을 갈라 준다(「추이」 「이번 회차」 「위험」). |
| **독자** | 부모 한 명에게 말한다(아이 이름은 3인칭). | 아이에게 말하는 칸을 따로 표시한다(「○○에게」). |
| **「이번 주」** | 통과 전이면 이번 회차 오답(재시 개념과 같게), 통과 후면 고질. | 늘 고질. |

**권고.** 판정 A, 독자 A, 이번 주 A. 코드는 각 한두 줄이고 문장 6개쯤을 선생님 말로 주시면 된다.
