# 서술형 연습 문항 — 교차 검증 명세 (품질 최우선, 전수)

너는 이 문항을 쓴 사람이 아니다. 쓴 사람의 판단을 믿지 말고 **문항마다 처음부터 직접 풀어** 반박을 시도하라.
입력: 이 폴더의 `chunk_NN.json`(concepts → 개념 코드 → items). 집필 명세는 `ESSAY_SPEC.md` — 먼저 읽어라.
참고(읽기만, `cd /home/user/dt && …`): appdata/forms_bank.json(개념·O/X 문장·reading), 그 과목 appdata/round_<과목>_NN.json, 화학Ⅰ 심화는 courses/ch1s/ 아래 자료,
화학Ⅰ·Ⅱ 선수노트 PDF(truthbooks/chem1_…, chem2_…), 해설지 HTML. 저장소는 고치지 마라. 커밋 금지.

## 문항마다 볼 것
1. **모범 답안 a 가 맞는가** — 직접 풀어 본다. 계산은 숫자를 다시 계산. 조건이 빠져 반례가 있으면 틀린 것.
2. **질문 q 가 답을 하나로 세우는가** — 학생이 다른 옳은 답을 써도 모범 답안·채점 기준으로 판정이 가능한가. 너무 열린 질문은 drop.
3. **key** 가 a 안에 있고, 그 개념의 핵심을 가리키는가(사소한 낱말·문장부호가 아닌가). 동의어 «|» 가 필요한데 빠졌으면 fix. key 가 질문 q 안에 이미 있거나 사소한 낱말이면 fix. 모범 답안이 len 최대치보다 길면 len 을 고친다.
4. **rubric** 3/2/1 이 그 문항에 맞게 구체적이고 서로 겹치지 않는가.
5. **범위**: 그 개념 first_round 회차까지 배운 내용인가(과목 자료로 확인).
6. **두 문항이 같은 판단을 되묻지 않는가**, O/X 문장을 «옳은지 쓰시오»로 바꾼 꼴이 아닌가.
7. 표기: 유니코드 첨자, 빼기 부호 −, 단위 띄어쓰기(25 °C), «**» 없음, 과정과 같은 상수값.
8. lvl·len 이 내용에 맞는가.

## 판정
- `keep` 문제없음 · `fix` 작은 수정으로 완전히 정확해짐(고친 항목 전체를 적는다) · `drop` 정답이 틀렸거나 애매·범위 밖·같은 판단. 조금이라도 의심되면 drop.

## 출력
`verify_NN.json`: {"chunk":N,"checked":n,"keep":n,"fix":n,"drop":n,"items":[{"code":"…","i":0,"verdict":"keep|fix|drop","why":"근거(fix/drop 필수)","item":{고친 문항 전체(fix)}}]}
`chunk_NN.verified.json`: keep + fix 적용본(같은 꼴, drop 은 뺌).
## 마지막 답(짧게)
묶음 번호, 전체/keep/fix/drop, drop 사유 유형별 수, 가장 심각했던 문제 3개.
