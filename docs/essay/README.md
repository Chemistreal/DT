## 핵심 낱말 대조 규칙 (essay.js keyCheck)
공백 무시 · 위/아래첨자·빼기 부호·×를 자판 글자로(NFKC) · 영문 대소문자 무시 · «|» 동의어 ·
불·비·무·반 + 한글 낱말은 안 걸림(«불안정» ≠ «안정») · 라틴 끝 글자 뒤 라틴이면 안 걸림(«12 M» ≠ «12 mol») ·
수 앞뒤가 숫자면 안 걸림(«49» ≠ «0.49», 전자 배치 1s²2s² 는 예외) · 끝 글자 받침 붙은 꼴 인정(«커지» = «커진다»).
key 는 «무엇이 어떻게»를 묶어 쓴다 — 방향 낱말만(«커진다») 두면 거꾸로 쓴 오답에도 걸린다.
점수는 매기지 않는다(서술형 판정은 선생님 몫) — 쓴 낱말 ✓ / 빠진 낱말 ○ 와 한 줄 자기 점검만.
